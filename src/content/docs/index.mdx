## Documentation principles

English is the canonical source language. The portal is structured for multilingual publishing, responsive use on desktop, tablet, and mobile devices, and light, dark, or automatic system themes.

Features that are not deployed yet are explicitly marked **Planned**. Product documentation remains separate from implementation repositories so each stack can evolve independently.
